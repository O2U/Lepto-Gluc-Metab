### Abstract

In this study, genome-scale metabolic modeling revealed that pathogenic Leptospira activates a previously overlooked glucose metabolic pathway in response to host body temperature (37°C).

---

### Repository Structure

This repository contains the code, data, and results required to reproduce the analyses presented in the manuscript.

- `/code`: All Python and R scripts used for the analyses
- `/data`: Raw data, processed data, and links to external datasets
- `/results`: Figures, tables, and metabolic models generated by the scripts
- `/manuscript`: Preprint of the manuscript

---

### Setup

We recommend managing the analysis environment using Conda. All software and libraries required for the analyses can be installed using the following command:

~~~bash
conda env create -f environment.yml
~~~

For details on the R environment, including version information, please refer to `R_session_info.txt`.
